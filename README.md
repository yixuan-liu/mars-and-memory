# Mars and Memory

An immersive, AI-driven interactive web experience powered by **Antigravity's Autonomous AI Developer Pipeline**.

This root directory acts as the orchestration control center for an automated team of specialized AI Agents.

## 🏗 Repository Structure

- **`.agents/`**: AI Orchestration Layer (Defines Personas, Skills, and Workflows).
- **`production_artifacts/`**: Output directory for AI-generated Technical Specifications.
- **`app_build/`**: The isolated Application Source Code (Turborepo).

## 💻 Documentation

- For development instructions, architecture details, and how to run the web application manually, please see the [Application README](./app_build/README.md).
- To trigger the autonomous pipeline to build new features, use the `/startcycle` command in your Antigravity IDE.
